# FPGA-Based 5G NR OFDM Communication System

## Overview
This project focuses on the design, implementation, and validation of an FPGA-based 5G NR OFDM communication system using MATLAB, Simulink, HDL Coder, Quartus Prime, and SignalTap on Intel DE10-Nano hardware.

The project includes FPGA deployment, waveform analysis, FFT/IFFT validation, BER/SNR evaluation, timing analysis, and runtime debugging workflows for validating OFDM communication behavior across multiple FPGA signal paths.

## Key Features
- FPGA-based OFDM transmitter implementation
- Fixed-point optimization workflows
- HDL generation and RTL development
- FPGA deployment and runtime validation
- FFT/IFFT signal-processing validation
- BER/SNR analysis
- Waveform capture and debugging
- SignalTap runtime analysis
- Python-based waveform parsing and automation utilities

---

## Validation Workflow
The project validates communication-system behavior using:
- SignalTap waveform captures
- Runtime FPGA debugging
- Timing analysis
- Synchronization validation
- FIFO-control verification
- Reset-sequencing analysis
- Hardware/software co-debugging workflows
